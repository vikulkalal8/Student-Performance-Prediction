The mathematics behind the model

All numerical matrices below are calculated from the active training split.

1 / Standardization

z = (x − μ) / σ

2 / Covariance

C = ZᵀZ / (n − 1)

3 / Eigenvalue decomposition

Cv = λv

4 / Projection & regression

T = ZVₖ
ŷ = β₀ + Tβ

Least squares minimizes the sum of squared residuals. PCA finds directions of maximum input variance, not necessarily maximum target predictability.

5 / Evaluation

MSE = Σ(y − ŷ)² / n
RMSE = √MSE
R² = 1 − SSE / SST

MAE is mean absolute error. R² can be negative; lower errors and higher R² are better on the same test set.
